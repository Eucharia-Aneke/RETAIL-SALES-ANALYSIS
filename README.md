Retail Sales Analysis Using Microsoft Excel

Project Overview

This project focuses on analysing retail sales data using Microsoft Excel to understand sales performance, identify trends, and generate useful business insights.

Project Objectives

* Analyse total revenue and sales performance.
* Identify the best-performing products.
* Compare sales across product categories.
* Examine monthly sales trends.
* Provide business insights and recommendations.

Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel formulas
* Excel Dashboard

Key Findings

* Total Revenue: ₦1,151,000
* Total Orders: 20
* Shoes Revenue: ₦545,000
* January Revenue: ₦515,000
* February Revenue: ₦636,000
* Highest-Revenue Product: Perfume (₦318,000)

Project Deliverables

* Cleaned sales dataset
* Product analysis
* Category analysis
* Monthly sales analysis
* Interactive sales dashboard
* Business insights and recommendations

Conclusion

This project demonstrates how Microsoft Excel can be used to clean, analyse, and visualise retail sales data to support better business decisions.
